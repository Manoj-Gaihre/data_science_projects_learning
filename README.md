### Project 2: Movie Rating Prediction

A regression project that predicts the rating of a movie based on features such as genre, director, actors, year, and votes.

Models used:

- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

Results:

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Linear Regression | 1.0157 | 1.2685 | 0.1345 |
| Random Forest | 1.0046 | 1.2573 | 0.1496 |
| Gradient Boosting | 0.9773 | 1.2285 | 0.1883 |

Best Result:

- Gradient Boosting achieved the lowest MAE and RMSE and the highest R² among the tested models.
